## Submitted files

- Chrome and Edge: `piclatch-0.1.0-chromium.zip`.
- Firefox desktop: `piclatch-0.1.0-firefox.zip`, with `piclatch-0.1.0-source.zip` for review.
- Each listing includes the icon and five screenshots. Chrome and Edge also have small and large promotional tiles.
- Privacy policy: <https://github.com/DeclanE47/piclatch/blob/main/PRIVACY.md>.
- Support: <https://github.com/DeclanE47/piclatch/issues>.

The published [v0.1.0 release](https://github.com/DeclanE47/piclatch/releases/tag/v0.1.0) contains both browser packages, the build source and SHA-256 checksums. Store graphics are in `store-assets/`; `scripts/store-assets.mjs` creates them from the extension interface and original sample illustrations.

## Future updates

Build and submit a new version for code changes. Keep the files attached to v0.1.0 unchanged so the release remains reproducible.
