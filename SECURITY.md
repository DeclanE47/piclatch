# Security reporting

Do not post private image URLs, authentication tokens or personal browsing information in public bug reports. Report vulnerabilities privately at https://github.com/DeclanE47/piclatch/security/advisories/new. Use public issues only for non-sensitive defects.

Treat page content as untrusted. Never insert image names as HTML or inject SVG markup. Do not add remote code, eval, proxy uploads or broader permissions without documenting the concrete need. Dependencies must be audited before a release.
